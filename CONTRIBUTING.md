# Contributing

Thanks for helping. Issues and pull requests are welcome.

- **Small pull requests**, one change each, with a clear description.
- **Tests first:** add or change the test in `test/` that shows the change, then the code. `npm test` must pass.
- **Generated pages:** edit `build.py`, run `python3 build.py`, and commit the `.html` files with it.
- **No credentials** in code, commits or issues. CI scans every pull request.
